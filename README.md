## Current direction

I am deepening my knowledge in:

* Security engineering and threat modelling
* Authentication, authorization, and identity systems
* Applied cryptography and secure key management
* Local-first and offline-capable software
* Operating-system security boundaries
* AI-assisted systems and agent security

Alongside my professional work, I am designing a long-term, security-focused credential platform for managing passwords, passkeys, API keys, certificates, machine identities, and access policies.

The goal is not to build a simple password-manager clone. I want to explore how credentials should be securely stored, synchronized, released, audited, and used by both humans and software agents—without relying on persistent plaintext secrets such as `.env` files.
